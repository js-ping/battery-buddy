# 电池管家 · Battery Buddy

macOS 菜单栏电池充电管理工具。给 [batt](https://github.com/charlie0129/batt) 做的图形界面。

菜单栏显示竖向电池图标（内部按电量填充），点开用滑动条调充电上限。

**自包含**：batt 已内置在 app 里，装完打开就能用，不需要单独安装。

---

## 功能

- 菜单栏竖向电池图标，内部按电量填充，跟随系统深浅色
- 滑动条调整充电上限，范围 50–100%，松手即生效
- 「保持当前电量」：把上限设为当前值，让固件停止放电
- 实时显示功率、容量、控制模式
- 首次启动自动铺开 batt 并安装后台服务（弹一次授权框）
- 菜单内可重装服务、可一键彻底卸载
- 不联网、无遥测、无第三方 SDK

## 兼容性

### 硬件

| 机型 | 支持 |
|---|---|
| Apple Silicon（M1 / M2 / M3 / M4） | ✅ 支持 |
| Intel Mac | ❌ 不支持 |

Intel 不支持是双重原因：`batt` 本身只实现 Apple Silicon 的电源控制；本 app 也只编译了 arm64 架构，Intel 上无法启动。

### 系统

| 系统 | 支持 |
|---|---|
| macOS 15 Sequoia | ✅ 已验证 |
| macOS 26 Tahoe | ✅ 预期可用 |
| macOS 13 / 14 | ⚠️ 可用，未充分验证 |
| macOS 11 / 12 | ⚠️ 不保证（batt 兼容性表标为未验证） |

### 充电控制方式会因固件而异

`batt` 会自动选择可用的控制后端，效果不同：

| 固件情况 | 后端 | 行为 |
|---|---|---|
| 老固件（macOS ≤15.7） | legacy | 直接开关充电，最精确，不放电 |
| 20xxx 固件（macOS 15.8+ / 26.7+ 安全更新下发） | firmware | 固件执行上下限：低于上限补电、**高于上限放电** |
| macOS 26.4+ | native | 系统原生充电上限，可配合 no-drain |

本项目开发机（MacBook Air M3 / macOS 15.8.2 / 固件 20457.41.3）属于第二种，所以会看到电量在上限附近反复小幅补电，且高于上限时会被放电到上限。这是固件行为，软件层无法关闭。

**想做到「高于目标只停充、绝不放电」，需要 macOS 26.4+ 的原生充电上限配合 `batt no-drain`。**

## 安装

1. 下载 `电池管家.dmg`，双击打开
2. 把 app 拖进「应用程序」
3. 首次打开会提示未验证开发者 → 系统设置 → 隐私与安全性 → 仍要打开
4. 启动后按提示点一次系统授权框（安装后台服务）

之后永久生效，开机自启。

**建议关闭系统的「优化电池充电」**：系统设置 → 电池 → 电池健康旁 ⓘ → 关闭。两者同时开启会互相干扰。

## 卸载

**方式一**：菜单栏图标 → 彻底卸载…

会停止服务、删除 batt 与所有配置、恢复系统默认充电行为，并删除 app 自身。

**方式二**：双击 dmg 里的 `卸载.command`

适用于 app 已损坏或已删除的情况，效果相同。

## 从源码构建

需要 Xcode 或 Command Line Tools（`swiftc`），仅支持 arm64。

```bash
./build.sh
```

产物：

- `build/电池管家.app`
- `build/电池管家.dmg`

构建时会自动把本机的 `~/.local/bin/batt` 打包进 app。若本机没有，产物不自包含，需自行下载 batt 放到该路径后重新构建。

## 结构

| 文件 | 作用 |
|---|---|
| `main.swift` | 全部应用代码，单文件，无第三方依赖 |
| `make_icon.swift` | 生成应用图标的 1024 底图 |
| `Info.plist` | app bundle 元信息（`LSUIElement=1` 纯菜单栏） |
| `build.sh` | 一键编译、打包、生成 dmg |

## 工作原理

app 本身不做任何电源控制，全部通过调用 `batt` 命令行完成：

- 启动时把内置的 batt 铺到 `~/.local/bin/batt`（若不存在）
- 检查后台服务是否注册，没有则弹系统授权框执行 `batt install`
- 面板每 20 秒异步读取 `batt status --json`，不阻塞主线程

## 数据安全

- 不联网，无遥测，无第三方 SDK
- 唯一的对外调用是本地执行 batt 命令行
- 不修改系统文件，不注入进程，不装内核扩展

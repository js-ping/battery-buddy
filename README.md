# 电池管家 · Battery Buddy

macOS 菜单栏电池充电管理工具。给 `batt` 做的图形界面。

菜单栏图标里直接显示当前电量数字，点开就能用滑动条调充电上限。

> **前置依赖**：本工具只是 `batt` 的界面，底层充电控制全部由 [batt](https://github.com/charlie0129/batt) 完成，必须先安装它。

## 功能

- **菜单栏图标内嵌电量数字**，不占 Dock，不显示文字
- **滑动条调上限**，范围 50–100%，松手即生效
- **保持当前电量**：把上限设成当前值，让固件停止放电
- 实时显示功率、容量、控制模式
- 电量高于上限且在放电时，面板内出橙色提醒
- 每 20 秒自动刷新

## 已知限制（重要）

这台机器（MacBook Air M3 / macOS 15.8.2 / 固件 20457.41.3）上，苹果把 SMC 充电控制键（`CHTE`/`CH0B`/`CH0C`）变成了零尺寸占位符，所有第三方直接控制充电的方案都失效了。

`batt` 在这种固件上会退到 **firmware-managed 后端**，由固件执行上下限。这个后端有两条硬规则，改不了：

| 情况 | 固件行为 |
|---|---|
| 电量低于上限 | 补电到上限 |
| 电量高于上限 | **放电到上限** |

也就是说：

- **做不到**「设定 80% 后，电量高于 80% 时只停充、不放电」
- 会看到电量在上限附近 1% 内**反复小幅补电**
- 想要真正「高于目标只停充」，需要 macOS 26.4+ 的原生充电上限，配合 `batt no-drain`（本机型当前固件不支持，`nativeExactTargets=false`）

界面里的 **「保持当前电量」** 是在这个限制下能达到「不放电」的唯一办法：把上限设成当前电量，固件就会静止。

## 安装

1. 先装 batt：

```bash
brew install batt
sudo brew services start batt
sudo batt install --allow-non-root-access
sudo batt limit 80
```

2. 下载 `电池管家.dmg`，双击打开，把 app 拖进「应用程序」

3. 首次运行会提示未验证开发者，去 **系统设置 → 隐私与安全性 → 仍要打开**

4. 关掉系统自带的「优化电池充电」：系统设置 → 电池 → 电池健康旁 ⓘ → 关闭

## 从源码构建

需要 Xcode 或 Command Line Tools（`swiftc`）。

```bash
./build.sh
```

产物：

- `build/电池管家.app`
- `build/电池管家.dmg`

## 卸载

```bash
# 退出 app 后
sudo batt uninstall          # 卸载守护进程并恢复默认充电行为
rm -rf /Applications/电池管家.app
```

如果只想移除界面、保留充电限制，跳过 `batt uninstall`，只删 app 即可。

## 结构

| 文件 | 作用 |
|---|---|
| `main.swift` | 全部应用代码，单文件，无第三方依赖 |
| `make_icon.swift` | 生成应用图标的 1024 底图 |
| `Info.plist` | app bundle 元信息（`LSUIElement=1` 纯菜单栏） |
| `build.sh` | 一键编译、打包、生成 dmg |

## 数据安全

- 不联网，无遥测，无第三方 SDK
- 唯一的对外调用是本地执行 `batt` 命令行
- 不修改系统文件，不注入进程，不装内核扩展
